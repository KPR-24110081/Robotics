# Homogeneous Transformation for Planar and Spatial Mechanisms

Implementation of homogeneous transformations for planar and spatial robotic mechanisms using **Python Robotics Toolbox** and **SpatialMath**.


---

## 📌 Overview

This project demonstrates how homogeneous transformation matrices can be used to represent and combine **translation and rotation** in robotic systems.

The implementation covers both:

- **Planar transformations (SE2)**
- **Spatial transformations (SE3)**

It also includes applications to:

- Sequential transformations
- Transformation-order comparison
- Coordinate-frame visualization
- Two-link planar robots
- Two-link spatial robots
- Complete transformation sequences

---

## 🎯 Objectives

The main objectives of this project are to:

- Generate homogeneous transformation matrices.
- Perform planar translation and rotation.
- Perform spatial translation and rotation.
- Combine multiple transformations.
- Determine final position and orientation.
- Visualize transformed coordinate frames.
- Understand the effect of transformation order.
- Apply transformations to simple robotic mechanisms.
